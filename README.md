# ADPulse

Independent advertising network for advertisers and verified publishers.

This repository contains the first production-oriented ADPulse MVP: publisher site verification and ad zones, advertiser campaigns, CPM/CPC accounting, ad serving, viewable-impression and click tracking, fraud/risk scoring, wallet ledger, publisher earnings, and admin moderation.

## Quick start

```bash
cp .env.example .env
npm install
npm run dev
```

Open http://localhost:3000

See `docs/ARCHITECTURE.md` and `docs/API.md` for the system model and API.
